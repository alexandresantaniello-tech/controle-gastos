# Sifia Core Bridge

Bootstrap temporario da ponte operacional do Sifia Core.

Principios:
- sem shell remoto arbitrario;
- comandos por allowlist;
- logs locais;
- nenhum segredo neste repositorio;
- operacoes sensiveis exigem aprovacao humana.

Este diretorio sera removido/migrado para um repositorio dedicado do Sifia Core quando a infraestrutura estiver estabilizada.
